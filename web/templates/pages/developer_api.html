Machine API

Authenticate with an API key as a bearer token. Keys carry the intersection of their own scopes and their owner's current permissions, so a key can never exceed the account it belongs to. 

curl -H "Authorization: Bearer pak_..." \
  {{.BaseURL}}/whoami

Responses

Failures are JSON with a stable code, never a redirect to a sign-in page: a client following that redirect reports a parse error instead of an authentication failure.

StatusCodeMeaning
401missing_credentialsNo bearer token was supplied.
401invalid_keyThe key is malformed, unknown or does not match.
401key_unusableThe key was revoked or has expired.
403address_not_allowedThe request did not come from an allowed address.
403owner_unavailableThe owning account no longer has an active profile.
403insufficient_scopeThe effective authority lacks the required permission.
429rate_limitedThe key's rate limit was reached. See Retry-After.
